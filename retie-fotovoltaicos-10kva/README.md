# Ruta RETIE fotovoltaica · 10 kVA

Aplicación web local de Servimeters para orientar la preclasificación de proyectos fotovoltaicos mediante preguntas simples.

## Uso

Abra `dist/index.html` o sirva la carpeta `dist` por HTTP. En este equipo se puede acceder durante la sesión en:

`http://127.0.0.1:8123/`

## Alcance

- Diferencia conexión a red, entrega de excedentes y sistema aislado.
- Identifica capacidad instalable o potencia instalada.
- Evalúa el umbral de 10 kVA con evidencia verificada.
- Cita el artículo 4.3.2.1, literal h o i, según la ruta.
- Escala los casos conectados sin excedentes o sin información suficiente.

La herramienta es de apoyo y no reemplaza la revisión integral del artículo 4.3.2.
